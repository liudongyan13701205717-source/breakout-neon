玩法说明

操作

  • ← → 或 鼠标：移动挡板
  • 空格 / 点击：发射小球
  • F：发射激光（有冷却）
  • G：能量满时释放超载
  • P：暂停  ·  Esc：返回主菜单

目标

  • 击碎全部可破坏砖块即可过关
  • 速通可获 时间奖励 额外加分
  • 球掉落则损失一条生命，生命耗尽即结束

BOSS 战 · 弹幕

  • BOSS 会向挡板瞄准散射并（高关）释放环形弹幕
  • 用球或激光猛击 BOSS 掉血，血条归零即击败（连击可加速）
  • 被弹幕击中会损失生命，注意走位躲避

砖块

  • 普通 · 硬砖(多次) · 爆炸(连锁)
  • 不可破坏 · BOSS(高血量，受击掉血并带霓虹命中反馈)
  • 相位砖：周期实体↔虚影，虚影时球可穿过
  • 引力井：吸引小球 · 再生砖：限次复活

道具 / 强化 / 元进度

  • 掉落：加宽 / 多球 / 减速 / 双倍星 / 穿甲 / 电磁脉冲
  • 每过一关三选一 永久强化
  • 每局获得 霓虹币，可在主菜单 永久升级（生命/挡板/激光/能量/连击/磁吸）

能量超载（终极技）

  • 击碎砖块积累 能量，满格按 G
  • 释放：短时加宽挡板 + 减速来球（纯增益，不跳关）

霓虹协议（Roguelike 增益）

  • 每关开局随机获得一项协议：疾速(球更快) / 富源(道具更多) / 双倍时(时间奖励×1.5)
  • 叠加 连击 倍率（连击越高分越高），让每局都不同
