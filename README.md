# 霓虹砖块 · Neon Breakout

霓虹赛博风的离线打砖块（Breakout）网页游戏。单文件玩法，**完全离线**，打开即玩，无任何联网请求、无账号、无后端。

## 怎么玩

直接双击 `index.html` 用浏览器打开即可，无需安装、无需服务器。

> 提示：请在浏览器中直接打开，或使用任意静态服务器。游戏进度与战绩保存在本机浏览器的 `localStorage` 中，不会上传到任何地方。

## 游戏内容

- **经典模式**：5 关精心设计的手工关卡，逐关解锁强化
- **无尽模式**：程序化波次，难度永无止境
- **BOSS 突袭**：连续挑战不断强化的巨型砖核（弱点核心、半血狂暴弹幕）
- **地图工坊**：画笔绘制自定义地图 / 分享码 / 导入导出，全部离线可用

## 操作

| 按键 / 操作 | 功能 |
| --- | --- |
| `←` `→` 或鼠标 | 移动挡板 |
| `空格` / 点击 | 发射小球 |
| `F` | 发射激光（有冷却） |
| `G` | 能量满时释放超载 |
| `P` | 暂停 |
| `M` | 静音 |
| `Esc` | 返回主菜单 |

## 特性

- 砖块：普通 / 硬砖（多次） / 爆炸（连锁） / 坚壁 / 相位（实体↔虚影） / 引力井 / 再生砖
- 道具：加宽 / 多球 / 减速 / 双倍 / 穿甲 / 电磁脉冲
- Roguelike 霓虹协议（每关随机增益）+ 连击倍率
- 元进度：霓虹币 / 永久升级 / 存档续玩 / 成就
- 霓虹辉光、拖尾、碎片破碎、命中停顿、震屏、全屏闪光

## 技术

- 纯 HTML / CSS / JavaScript，无构建步骤
- 物理：`matter.min.js`（Matter.js，MIT 授权，随仓库附带）

## 文件

```
index.html        页面与 UI
style.css         样式
game.js           全部游戏逻辑
matter.min.js     物理引擎（第三方，MIT）
```

## 隐私

本游戏无任何联网功能，不上传任何数据。所有进度（最高分、成就、霓虹币、存档、自定义地图）仅保存在你自己浏览器的 `localStorage` 中。
